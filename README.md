# WellBite — Every Bite, Better Living
Tracker makan, minum, dan berat badan harian (PWA). Created by CreanovativeCo.

## Cara upload ke GitHub Pages
1. Di GitHub buat repository baru bernama **wellbite** (Public).
2. Klik **Add file → Upload files**, lalu upload SEMUA file di folder ini (tanpa folder `src`).
3. Buka **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. Tunggu 1–2 menit, buka https://niesyaputri.github.io/wellbite/
5. Di iPhone: buka link di Safari → tombol Bagikan → **Tambahkan ke Layar Utama**.

Kode undangan sama dengan AgendaKu (config.js disalin dari AgendaKu).
Kalau nanti mengunggah versi baru, ubah `CACHE = 'wellbite-v2'` di sw.js (v2 → v3).
